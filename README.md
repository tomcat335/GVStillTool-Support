 # GV Still Tool — Support                                                                                                                                          
                                                                                                                                                                     
  **GV Still Tool** is a macOS utility for viewing and converting GVG K-Frame (`.eif`) and GVG Kayenne Classic (`.kif`) broadcast still image files.                 
                                                                                                                                                                     
  ---                                                                                                                                                                
                                                            
  ## Reporting a Bug or Getting Help                                                                                                                                 
   
  Use the [Issues](../../issues) tab to:                                                                                                                             
  - Report a bug                                            
  - Ask a question                                                                                                                                                   
  - Request a feature                                       

  Please include the following when reporting a bug:                                                                                                                 
  - macOS version (e.g. macOS 15.3)
  - What you were doing when the problem occurred                                                                                                                    
  - What happened vs. what you expected                                                                                                                              
  - The filename and format (`.eif` or `.kif`) if relevant
                                                                                                                                                                     
  ---                                                       
                                                                                                                                                                     
  ## Frequently Asked Questions                             

  **What file formats are supported?**                                                                                                                               
  GV Still Tool supports `.eif` files from GVG K-Frame systems and `.kif` files from GVG Kayenne Classic systems.
                                                                                                                                                                     
  **Can I convert between formats?**                        
  You can export stills to PNG from both formats using the Convert tab or ⌘⇧E.                                                                                       
                                                                                                                                                                     
  **The image looks wrong / colours are off — what should I do?**                                                                                                    
  Open an Issue with the filename and a screenshot. Include whether the file came from a K-Frame or Kayenne system.
